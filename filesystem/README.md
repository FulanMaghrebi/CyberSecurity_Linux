# Filesystem

This README deals with all the different commands to operate with the filesysten.

##PWD

prints current working directory

##Combines

'-L' shows the logical path to destination
'-P' shows physikal path to destination

##ls

list files and directories of current directory

##combines

'-l' detailled view
'-a' shows hidden files
'-h' human readable transforms 4096 Byte to 4KB
